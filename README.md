🎬 Netflix Clone (HTML, CSS & JavaScript)

A responsive Netflix landing page clone built using HTML5, CSS3, and basic JavaScript.
This project focuses on recreating the UI, layout, and user experience of Netflix’s homepage.

🌟 Project Overview

This project is a front-end clone of the Netflix India homepage.
It includes a modern design, smooth layout structure, and responsive sections similar to the real Netflix website.

✔️ Built for learning real-world UI design
✔️ Beginner–friendly project
✔️ Resume & portfolio ready

🔥 Features

🎨 Netflix-style modern UI

📱 Fully responsive (Mobile, Tablet & Desktop)

🌍 Language selector (English / हिन्दी)

🎥 Trending movies section

📦 Feature cards (TV, Offline Download, Profiles, etc.)

❓ FAQ section with clean layout

📨 Email input & CTA buttons

🦶 Professional footer layout

🛠️ Technologies Used

HTML5 – Page structure

CSS3 – Styling & responsiveness

JavaScript – Basic interactivity

SVG & WebP images – Optimized assets
